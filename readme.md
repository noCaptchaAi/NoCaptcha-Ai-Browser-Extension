## How it works

Install → paste your API key → browse normally. The extension detects CAPTCHAs on any page and solves them in the background. No clicks, no puzzles, no interruptions.

---

## Why NoCaptchaAI

- **Actually fast** — solves fire before you even notice the CAPTCHA
- **Works everywhere** — 12+ CAPTCHA types across thousands of sites
- **Proxy & UA rotation** — built-in HTTP, SOCKS4/5 proxy support with per-request rotation and User-Agent spoofing
- **Site blacklist** — turn it off for specific domains
- **Region failover** — backup API endpoints for users in restricted regions
- **24 languages** — Bengali, Japanese, Arabic, Korean, Russian, and more
- **Balance tracking** — check your remaining quota right from the popup

## Getting started

1. Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/nocaptcha-ai-auto-captcha/hbnbcapieoandchfgacedlkjpdbbejgb), [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/nocaptcha-ai-captcha-solver/), or grab a build from [Releases](https://github.com/noCaptchaAi/NoCaptcha-Ai-Browser-Extension/releases)
2. Get your API key at [dash.nocaptchaai.com](https://dash.nocaptchaai.com)
3. Open the extension popup, paste your key, done

> **Manual install?** Chrome/Edge/Brave: extract the `.zip`, go to `chrome://extensions`, enable Developer mode, Load unpacked. Firefox: download the `.xpi`, go to `about:addons`, Install from file.
